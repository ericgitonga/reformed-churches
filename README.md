# reformed-churches

A directory of Reformed churches in Nairobi (and beyond), with location, pastor, and contact
details. Built with Next.js, deployed on Vercel.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Church data lives in `src/data/churches.json`. See `CHANGELOG.md` for release history.
